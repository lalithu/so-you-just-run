## What is this Knowledge Map?

This page is a **Java Knowledge Map** built for ITSC 2214.

It visually represents the major concept areas in Java and data structures,
how they decompose into subtopics, and how those topics relate to one another.

The goal is **fast recall and conceptual navigation**, not step-by-step teaching.
Clicking on any node in the map jumps to the corresponding section below, allowing
you to zoom in on a specific concept while keeping the full mental structure in view.

This map reflects both topics I have already studied and topics I revisit to
reinforce long-term understanding.
